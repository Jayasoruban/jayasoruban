# Embedded software engineer

Software that sits next to hardware, plus the AI and application code around it. The working stack is embedded software, AI, .NET, and Python.

## Experience

Embedded work covers device-side programs and the services that run beside them. AI is added inside an existing system: a model that the product can call, check, and keep running. .NET and Python are the two languages that code is written in.

## Focus

- **Embedded software.** Device-side programs, long-running services, and tools that talk to hardware.
- **AI.** Model integration, from a working model to a service a product can call.
- **.NET.** C# services and application code.
- **Python.** Tooling, automation, and the AI integration path.

## Stack

Embedded software, C#, .NET, Python, Docker, Git.
